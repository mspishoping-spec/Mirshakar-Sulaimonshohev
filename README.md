# 汉语 карточки — первая версия

Бесплатный локальный тренажёр китайских слов для iPhone.

## Что умеет
- Карточки с иероглифами, пиньинем с тонами, переводом и примером.
- Интервальные повторения с кнопками «Забыл», «Трудно», «Хорошо», «Легко».
- Добавление слов вручную.
- Импорт CSV и JSON, экспорт CSV и резервной копии JSON.
- Локальное сохранение в браузере без аккаунта.
- Основа PWA для добавления на экран «Домой» и офлайн-работы при размещении на HTTPS-хостинге.

## Важно про iPhone
iOS не всегда запускает JavaScript из HTML-файла, открытого через приложение «Файлы». Чтобы пользоваться как приложением:
1. Бесплатно размести эти файлы на статическом HTTPS-хостинге, например GitHub Pages.
2. Открой опубликованный HTTPS-адрес в Safari.
3. Нажми «Поделиться» → «На экран Домой» → «Добавить».
4. Открой иконку с экрана «Домой».

Пока данные хранятся локально в браузере на устройстве. Не очищай данные Safari без экспорта JSON-резервной копии. Для синхронизации между устройствами понадобится отдельная облачная база, но это не требуется для первой версии.

## CSV формат
Первая строка должна быть заголовком:
hanzi,pinyin,meaning,example
你好,nǐ hǎo,привет,你好！(Nǐ hǎo!) — Привет！
谢谢,xièxie,спасибо,谢谢你！(Xièxie nǐ!) — Спасибо тебе！

## Алгоритм
Упрощённая схема в духе SM-2, не точная реализация оригинального алгоритма. «Забыл» возвращает карточку примерно через 10 минут, «Трудно» назначает короткий интервал, а «Хорошо» и «Легко» постепенно увеличивают интервалы.
