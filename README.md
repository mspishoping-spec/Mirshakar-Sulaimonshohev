# 汉语 карточки — обновлённая версия

Бесплатный локальный тренажёр китайских слов для iPhone.

## Что изменено
- На лицевой стороне карточки показывается только иероглиф. Пиньинь, перевод и пример появляются после нажатия «Показать ответ».
- Интервалы рассчитываются по календарным дням: повтор назначается на начало соответствующего дня, а не через точные 24 часа.
- «Забыл» возвращает карточку в конец текущей сессии. Две дополнительные попытки в этой сессии; после третьего нажатия «Забыл» карточка вернётся завтра.
- Словарь и импорт/экспорт CSV/JSON сохранены.

## Важно: сохранение твоих слов
Ключ локального хранилища `hanziFlashcards_v1` не изменён. Если ты обновишь файлы в том же GitHub Pages-адресе и не очистишь данные Safari, существующие слова останутся на устройстве. Перед обновлением всё равно рекомендуется экспортировать JSON-резервную копию.

## CSV формат
`hanzi,pinyin,meaning,example`

## Установка
Размести все файлы в корне GitHub Pages, открой сайт в Safari и выбери «Поделиться» → «На экран Домой».
